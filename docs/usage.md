# 使用说明

1. 调用 `dsh-we-wallpaper-sync` 技能，或直接读 `SKILL.md`。
2. 准备：Docker、Steam Web API Key、已购买 Wallpaper Engine（431960）的账号、一个出口 IP 与账号常住地一致的代理。
3. 按顺序：验代理出口 IP → 搜索/浏览 → steamcmd 下载 → 设 `~/.dsh/settings.yaml` 的 `skin-wallpaper.weLibraryDirs` → 到皮肤中心壁纸面板应用。

常见结果：scene 类在 Linux 上为静态帧；video / web 类可真动态。
